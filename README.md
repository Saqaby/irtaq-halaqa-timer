# مؤقت حلقة ارتق

صفحة لمعلمي حلقات برنامج «ارتق» لتحفيظ القرآن الكريم، تعطي كل طالب مؤقتاً خاصاً به أثناء التسميع.

## المزايا

- حفظ أكثر من حلقة، ولكل حلقة أسماء طلابها (من ٢ إلى ٢٠ طالباً).
- مؤقت تصاعدي لكل طالب، ويمكن تحويل أي طالب إلى مؤقت تنازلي مع تنبيه وصوت قصير عند انتهاء الوقت.
- تبدأ كل يوم جديد وبطاقات الطلاب مجمّدة، وتفعّل بطاقة الطالب الحاضر بالضغط على اسمه فتنتقل إلى الأعلى.
- زر ✓ لتجميد بطاقة الطالب بعد أن ينجز، فتنتقل إلى الأسفل مع الوقت الذي استغرقه.
- دمج بطاقتين بالسحب والإفلات ليسمّع طالبان معاً بمؤقت واحد، وزر «فصل» لإعادتهما بطاقتين.
- أزرار لضبط وقت جميع الطلاب مرة واحدة: ٣ أو ٥ أو ١٠ أو ١٥ دقيقة.
- عرض المؤقتات في مربعات تظهر في شاشة واحدة.

## أين تُحفظ البيانات؟

تُحفظ الحلقات وأسماء الطلاب في متصفح الجهاز نفسه (localStorage)، ولا تُرسل إلى أي خادم.
لذلك تظهر البيانات فقط على الجهاز والمتصفح الذي أُدخلت فيه، وتُحذف إذا مُسحت بيانات المتصفح.

## التشغيل

افتح الصفحة من رابط GitHub Pages، أو نزّل الملفات وافتح `index.html` في أي متصفح.
